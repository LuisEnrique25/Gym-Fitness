# Gym & Fitness — React

A responsive fitness website rebuilt with React, based on a project originally developed using HTML, CSS, and vanilla JavaScript.

## 📌 Project Overview

Gym & Fitness is a personal learning project focused on rebuilding an existing fitness website using React.

I first recreated the website using HTML, CSS, and vanilla JavaScript by following a YouTube tutorial. After completing that version, I decided to rebuild it with React to practice component-based development, improve code organization, and create a more maintainable and responsive application.

The React version preserves the original website's overall concept while applying reusable components, dynamic content rendering, and responsive styling.

## ✨ Features

- Responsive layout for different screen sizes.
- Navigation bar with a mobile menu.
- The Hero section is presented in the center.
- Program section presented via JSON.
- About Us section.
- Pricing plans rendered dynamically from JSON data.
- Reusable components for pricing cards.
- Contact section with a functional button.
- Scroll progress indicator.
- Active navigation links based on the current scroll position.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- React
- Vite

## 📂 Project Structure

The project is organized into reusable React components, with separate stylesheets and data files to improve code organization and maintainability.

- `src/components/` — reusable UI components and css files.
- `src/assets/db/` — JSON data used to render dynamic content.

- Building reusable components with React.

- Implementing responsive layouts with CSS.
- Separating component logic and styles.
