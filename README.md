## 🎨 Credits and Inspiration

This project was inspired by a YouTube tutorial in which a fitness website was built using HTML, CSS, and vanilla JavaScript.

I first recreated the website using these technologies in my [GymPage repository](https://github.com/LuisEnrique25/GymPage). Later, I decided to rebuild it with React to practice component-based development, improve code organization, and make the layout responsive across different screen sizes.

The React version includes my implementation of reusable components, dynamic content rendering, and interactive features adapted to React.

**Original tutorial:** [YouTube – Gym & Fitness Website](https://www.youtube.com/watch?v=1CRBrvIBvFg)

**Original implementation:** [GymPage – HTML, CSS & JavaScript](https://github.com/LuisEnrique25/GymPage)

This project was developed for educational and portfolio purposes.
